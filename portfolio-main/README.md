## 🌐 Free 1-Click / Free Permanent Cloud Deployment Options

Since this is a high-performance static website (HTML5, CSS3, JavaScript), it can be deployed to any of the following free platforms in seconds:

### Option 1: Netlify Drop (Instant Drag & Drop — 30 Seconds)
1. Go to [https://app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the `cyber-portfolio` folder directly into the browser window.
3. Your website is instantly live with a free custom SSL URL (e.g. `vamsi-cybersecurity.netlify.app`).

---

### Option 2: Vercel (Free Global CDN)
1. Install Vercel CLI (or go to [https://vercel.com](https://vercel.com)):
   ```bash
   npx vercel
   ```
2. Follow the 2 prompts in your terminal to deploy instantly to `https://vamsi-cybersecurity.vercel.app`.

---

### Option 3: GitHub Pages (Free Hosting on your GitHub)
1. Create a new GitHub repository named `vamsi-portfolio` or `<your-username>.github.io`.
2. Upload `index.html`, `styles.css`, and `script.js`.
3. In repository **Settings** → **Pages**, select `main` branch as the source and click **Save**.
4. Your website will be live at `https://<your-username>.github.io/`.

---

### Option 4: Cloudflare Pages
1. Go to [https://pages.cloudflare.com](https://pages.cloudflare.com).
2. Upload the `cyber-portfolio` directory.
3. Enjoy lightning-fast global edge hosting with free SSL and custom domain support.
